Routines prototype

A clickable version of docs/design/screens/routines.md, for mobile. It opens on the Workout tab. Tap Manage to reach the Routines screen. Everything is example data.

Scenario

App theme

Things to try

  • Workout tab: tap a routine for the preview. Tap Manage for the Routines screen.
  • Row ⋯: Rename, Duplicate, Share (copies text), Delete, then Undo.
  • "Change order": drag the handles, then Done.
  • Edit a routine: − / + for warm-up and sets, a note via ⋯, Add exercise, Remove. Then Save, or Cancel after a change.
  • + to create a new routine: Save only works with a name and at least one exercise.
  • "No routines yet": add starter routines with one tap.
