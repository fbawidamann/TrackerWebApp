# Prototypes

Clickable HTML mockups made during design planning. Each is one self-contained file. Open it in a browser by double-clicking (it needs internet access for the IBM Plex Sans font). They use example data and save nothing.

These files are **design references, not app code**. The real app is built with React in `apps/web`. When a design changes, update the spec in `docs/design/` first. Update a prototype only if it still helps.
