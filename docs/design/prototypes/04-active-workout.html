Active workout prototype

A clickable version of the spec in docs/design/screens/active-workout.md. It works on PC and phone. Everything is example data and nothing is saved.

Scenarios

"Running Push Day" starts 34 minutes in, with 2 sets done and the rest timer running.

App theme

Things to try

  • Tap ✓ with empty fields: the grey values are used. Only without any grey value (e.g. Calf Raise, never done before) it asks you to type.
  • Press Enter in a field to jump kg → reps → next set.
  • Log 82.5 kg on Bench Press to get a PR in the summary.
  • Tap a set number (1, 2, W) for Warm-up / Normal / Delete.
  • Swipe a set row left to delete it. On PC, click and drag left. Then try Undo.
  • Tap the rest time for −15 / +15. Let it run out to see the count-up.
  • Exercise menu (⋯): Replace, Note, Reorder (drag the handles), Remove.
  • Tap the title to rename the workout.
  • Go to another tab: the mini bar appears above the nav.
  • Add several exercises at once, then Finish. With unfinished sets it asks first. Changing a routine workout offers to update the routine.
  • Profile: change the rest time.

Not in this prototype

Keeping the screen on, the 12-hour check for a forgotten workout, saving to the database, and History / Exercises content.
