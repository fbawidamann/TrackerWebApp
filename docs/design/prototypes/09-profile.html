Profile and settings prototype

A clickable version of docs/design/screens/profile.md, for mobile. Theme, accent colour, text size and navigation labels take effect in the prototype right away. The formats show a live example line. Nothing is saved.

Things to try

  • Tap the name to rename.
  • Appearance: switch the accent colour, text size and theme, and watch the whole app change.
  • Turn the rest timer off: the two rows below it disappear.
  • Units and formats: kg/lb, decimal comma and date format. See the example line.
  • Rows with › open a bottom sheet (weekly goal, weight step, rest time, and so on).
  • Import backup: pick a file, or use "Try with example backup".

Note

Downloads are blocked in this preview, so Export backup only shows a message. In the app it saves or shares the file.
