History prototype

A clickable version of docs/design/screens/history.md, for mobile. The example data is 10 weeks of training up to today, Wednesday, 30 September. Nothing is saved.

Card style in the list

A every exercise with "sets · best". B exercise names as one calm line (max 2 lines), numbers only for PRs. C at most 3 lines, PR exercises first, "+3 more exercises". D like B, with "Show sets and best" to expand a single card.

App theme

Things to try

  • Scroll the weeks. Every card shows exercise lines with "sets · best" and a medal for PRs.
  • Search squat or curl: only matching workouts stay, with the exercise highlighted.
  • Filter button: pick routines or "Freeform", then remove them with the chips.
  • Open a workout: Duration · Sets · PRs, then the exercise cards.
  • ⋯ → Edit workout: change name, date, time, duration, kg/reps, add a set or exercise, then Save. Also try Cancel after a change.
  • ⋯ → Delete workout, then Undo. ⋯ → Save as routine.
  • + (top right in History): log a past workout, and try "Start from Push Day".
  • Calendar icon (top right): blue dots mark training days. Tap a day to see its workouts, and switch months with ‹ ›.
